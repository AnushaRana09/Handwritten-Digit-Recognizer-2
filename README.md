**Handwritten Digit Recognizer**

Project Overview
A Machine Learning project that recognizes handwritten digits using the K-Nearest Neighbors (KNN) algorithm.

Objective
To build a machine learning model that can identify handwritten digits from image data and predict the correct digit.

 Technologies Used
- Python
- Scikit-learn
- Matplotlib
- K-Nearest Neighbors (KNN)
- Google Colab

Dataset
The project uses the built-in Digits dataset from Scikit-learn.
- 1,797 handwritten digit images
- Images are represented using numerical pixel values
- Each image represents a digit from 0 to 9

Methodology
1. Load the Digits dataset
2. Visualize handwritten digit images
3. Split the dataset into training and testing sets
4. Train a KNN classifier
5. Predict digits from test data
6. Evaluate the model using accuracy and classification metrics
7. Test the model with individual digit images

Model Performance
The KNN model achieved approximately 98.33% accuracy on the test dataset.

Result
The trained model successfully recognizes handwritten digits and predicts the corresponding numerical class.
